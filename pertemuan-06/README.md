# pertemuan-06


Pada praktikum pertemuan ke-6 ini, saya akan melanjutkan pengembangan proyek dari pertemuan sebelumnya, yaitu P5, sebagai dasar pengerjaan. Saya akan membuat salinan proyek ke dalam folder pertemuan - 06/ agar proyek P5 tetap aman dan tidak mengalami perubahan.

Pada P6 ini, saya akan mempelajari dan menerapkan penggunaan PHP untuk membuat halaman web yang dinamis. Saya juga akan menggunakan variabel, konstanta, tipe data, dan operator untuk mengolah data di dalam program.

Selain itu, saya akan menerapkan percabangan if - elseif - else dan switch untuk menentukan kondisi program, serta perulangan for dan while untuk menjalankan perintah secara berulang sesuai kebutuhan.

Setelah proses pembuatan program selesai, saya akan menjalankan dan menguji aplikasi melalui localhost untuk memastikan fitur yang dibuat dapat berjalan dengan baik. Jika ditemukan kesalahan, saya akan melakukan debugging dan memperbaiki kode sampai hasilnya sesuai dengan yang diharapkan.

Saya juga akan membuat dokumentasi pada file pertemuan - 06/README.md yang berisi penjelasan perubahan dari P5 ke P6, cara menjalankan program, dan hasil pengujian yang telah dilakukan. Untuk mengelola perkembangan proyek, saya akan menggunakan Git dan GitHub agar setiap perubahan kode dapat disimpan secara bertahap dan memiliki riwayat yang jelas.

Melalui praktikum ini, saya berharap dapat lebih memahami dasar-dasar PHP dan mampu menerapkannya dalam pengembangan halaman web dinamis. Saya juga ingin membiasakan diri dalam melakukan pengujian, memperbaiki kesalahan program, membuat dokumentasi, serta mengelola proyek dengan Git/GitHub.

Target akhir dari praktikum ini adalah menghasilkan proyek P6 yang berjalan dengan baik, memenuhi seluruh ketentuan dalam modul, memiliki dokumentasi yang lengkap, dan tetap terpisah dari proyek P5 sebagai versi sebelumnya.
